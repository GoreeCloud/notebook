# Intended product benefits

- Ownership of the self-hosted knowledge database, backups and export paths.
- Consolidated notes, documentation, links, attachments and web captures.
- Flexible hierarchy, metadata and navigation for deep knowledge bases.
- A unified GoreeCloud user experience governed by Glaze semantics.
- Lower migration friction from Evernote through repeatable, inspectable imports.

**Validation:** These are product objectives. Actual security, sync quality, migration fidelity, performance and Glaze accessibility are pending independent acceptance tests.
