# GoreeCloud Notebook — Competitive Objectives

**Source and status:** Founder-directed Evernote + TriliumNext synthesis, November 6, 2026. Strategic objectives only; competitor releases and prices were not independently reverified during implementation.

| Reference product | Feature inspiration | GoreeCloud target | Current preview |
| --- | --- | --- | --- |
| Evernote | Fast capture, web clipping, scanning, tasks, calendars | Premium low-friction creation, capture and productivity with user-controlled data | Basic notes and tasks |
| TriliumNext | Unlimited-depth trees, attributes, cloning, scripting, graphs, self-hosting | Deep linked knowledge, personal ownership and secure extensibility | Basic hierarchy, stable-ID and title backlinks |
| OneNote | Freeform documents, pen, notebooks, device use | Expressive canvas and structure | Not implemented |
| Notion | Structured collections and collaboration | Flexible workspaces and controlled team publishing | Not implemented |
| Obsidian | Markdown, links, plugins and graph | Open exports, durable links and local-first graph | Basic links and JSON backup |
| Joplin | Open-source notes and optional sync | Portable formats, private hosting and durable offline workflows | Browser-local only |

## Recommended competitive differentiators

1. GoreeShield privacy-first consent and minimized collection.
2. Wardveil-reviewed authentication, encryption, permission controls and threat model.
3. Portable hierarchical knowledge with stable links and typed relationships.
4. Official GC UI design and accessibility acceptance, not generic starter screens.
5. Recoverable local-first workflows and opt-in GoreeCloud Mesh sync.
6. GoreeCloud AI only with individually permitted context and clear model choice.
7. Sustainable first-party software with minimal dependencies and independent hosting.

**No parity claim:** The development preview does not yet replace all features of any named competitor.
