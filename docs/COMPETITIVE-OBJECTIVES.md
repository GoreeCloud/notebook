# Competitive objectives — Evernote alternative

GoreeCloud Notebook aims to match essential Evernote capture, search, rich note composition, organization, attachments, web clipper, notebooks/tags and note portability, while distinguishing itself through privacy-first self-hosting, flexible knowledge structures and GoreeCloud ecosystem integration.

Do not claim competitive superiority without current, reproducible comparisons. Before release, benchmark import fidelity, large-notebook search, reliable offline edits, attachment performance, sync conflicts, accessibility, mobile composition, export completeness and 90-day upgrade/restore expectations. Record methodology and objective outcomes rather than marketing guesses.
