# GoreeCloud Notebook — Consolidated Product Specification

**Source:** Founder-directed GoreeCloud Notebook features and capabilities catalog, November 6, 2026.  
**Status:** Intended product scope, not a list of shipped features. Consult Implemented Features and Planned Features documents for evidence-based delivery status.

**Vision:** One intelligent workspace to capture, create, organize, connect, discover, manage and protect knowledge.

## Capability domains

1. **Notes and content:** Rich text, plain text, Markdown, code, quick capture, journals, meetings, templates, autosave, revisions, archive and recovery.
2. **Editing:** Typography, headings, checklists, nested outlines, tables, LaTeX, code blocks, links, embeds, callouts, full screen and distraction-free writing.
3. **Hierarchy:** Notebooks, stacks, folders, workspaces, unlimited-depth trees, tags, inherited attributes, cloning into multiple branches, hoisting and saved views.
4. **Knowledge connections:** Backlinks, typed relations, entity graphs, note maps, clusters, concepts and link recommendations.
5. **Special note types:** Text, code, HTML, file, PDF, spreadsheet, journal, task, calendar, search, canvas, diagram, Mermaid, relation map, mind map and geographic map.
6. **Web capture:** Browser clipping, entire pages, simplified articles, selections, screenshots, bookmarks, source metadata, deduplication and offline access.
7. **Scan/OCR:** Camera scans, edge detection, multi-page PDFs, handwriting recognition, business cards, receipts, whiteboards and searchable scans.
8. **Document library:** Attachments, PDF and image previews, annotation, merge/split, extraction, metadata, version history and document reuse.
9. **Discovery:** Full-text, filtered and saved search, metadata, relations, OCR, transcriptions, natural-language and semantic retrieval.
10. **GoreeCloud AI:** Writing help, summaries, contextual questions, organization, transcription, task extraction, links, model choice, local inference and granular permissions.
11. **Tasks:** Notes-to-tasks, checklists, due dates, recurrence, reminders, priorities, assignments, project views, dashboard tracking and AI extraction.
12. **Calendar:** Multiple views, event-linked notes, external calendars, meetings, reminders, planning and deadlines.
13. **Meetings:** Recording with consent, transcription, speaker identification, summaries, timestamps, follow-ups, searchable audio and retention controls.
14. **Collaboration:** Shared notes and spaces, roles, permissions, comments, access revocation, publishing and public read-only documentation.
15. **Dashboards:** Home, recent notes, favorites, tasks, widgets, custom panels, layouts, focus views and mobile navigation.
16. **Automation:** Frontend/backend scripts, safe sandboxing, scheduled triggers, widgets, webhooks, REST APIs, MCP and external integrations.
17. **GoreeShield privacy:** Data minimization, transparency, consent, control of tracking, AI access, retention, export and sharing preferences.
18. **Wardveil cybersecurity:** Encryption, authenticated access, session security, authorization, suspicious behavior, audit, vulnerability monitoring and recovery.
19. **GoreeCloud Mesh:** Connectivity, synchronization, retries, conflicts, health, cross-product communication and privacy/security enforcement.
20. **Platforms:** Browser/PWA, Windows/macOS/Linux, Android/iOS/tablets, offline editing, cloud or self-hosted sync and recovery.
21. **Self-hosting:** Docker, private servers, database configurations, administration, metrics, backup, restore and independent operation.
22. **Migration:** Markdown, HTML, PDF, ENEX, OneNote, Notion, Keep, Anytype, portable export, metadata preservation and migration reports.
23. **GoreeCloud UI:** Canonical design tokens, premium layouts, semantic color, accessible typography, keyboard/screen-reader operation, responsive interaction and reduced motion.
24. **Administration:** Users, workspaces, permissions, sessions, storage, logging, audits, jobs, monitoring, backup, diagnostics and releases.
25. **Intelligent organization:** Inbox, filing, tagging, duplication detection, orphan notes, broken links, reviews, health checks and approved bulk actions.
26. **Uses:** Personal knowledge, journaling, research, education, technical notes, business documentation, team wikis, archives, travel and creative work.
27. **Architecture:** Note core, knowledge, library, capture, search, AI, tasks, calendar, canvas, workspace, collaboration, automation, synchronization, privacy, security, identity, Mesh, UI and administration.
28. **Engineering:** Local-first, data ownership, security/privacy by design, accessible, modular, portable, scalable, maintainable, tested, verified and user-controlled.

## Delivery interpretation

The 28 domains are long-term intended capabilities. Some are present only as basic v0.1 foundations (e.g. a simple editor, tree, search and tasks). Neither competitor feature parity nor production support is claimed. Each material feature must pass tests, data-security and privacy review, and UI acceptance before promoting its status.
