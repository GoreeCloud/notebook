# Features and capabilities

GoreeCloud Notebook targets an Evernote-style capture-to-knowledge workflow while retaining selected TriliumNext behavior. **Upstream source present does not imply this derived product has been qualified.**

| Area | Upstream source baseline | GoreeCloud acceptance |
| --- | --- | --- |
| Hierarchical notes and note cloning | Imported | Unverified |
| Rich-text, code and table editing | Imported | Unverified |
| Full-text search and attributes | Imported | Unverified |
| Note revisions and backlinks/maps | Imported | Unverified |
| Attachments and import/export | Imported | Unverified |
| Evernote ENEX migration | Imported | Needs sample and safety tests |
| Self-hosted web/desktop/sync | Imported | Needs security and data tests |
| Web clipper | Imported | Needs browser/privacy checks |
| Glaze visual and interaction semantics | First stylesheet adapter in development | Nonconforming until consumer acceptance |
| Mobile/adaptive experience | Imported upstream support | Needs representative-device tests |

The owner's [complete feature and capability vision](COMPLETE-FEATURES-AND-CAPABILITIES.md) covers 20 product domains, spanning capture, editing, organization, knowledge graphs, search, databases, tasks, calendar, visual planning, collaboration, optional AI, privacy, sync, publishing, automation, personalization, portability, specialized content, projects and hosting. **That full catalogue is proposed product scope and does not change the unverified acceptance statuses above.**
